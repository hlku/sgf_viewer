sgf_parser
-------
A simple parser that can show a board of an SGF file.  
I wrote this parser to practice `Python` re module, it contains a bit of bugs.  

It's written in `Python2`, which is obsolete. It uses the `visual` library which is only used in `Pyhton2`. In `Python3`, the library is adapted to `vpython` library, but `vpython` still has some error remaining to fix (like using obsolete library `pkg_resources`). So this parse will wait upgrading till `vpython` library get fixed.
